### 2. Master data กลุ่ม / ผู้รับ สำหรับฟอร์มเพิ่มงาน (ใหม่)
ไฟล์: [Controllers/ListOfValuesController.cs](../Controllers/ListOfValuesController.cs),
[Dtos/EmployeeGroupResponse.cs](../Dtos/EmployeeGroupResponse.cs) (ใหม่),
[docs/GetEmployeeGroup.md](GetEmployeeGroup.md) (ใหม่), [docs/GetEmployeeByGroup.md](GetEmployeeByGroup.md) (ใหม่)

ทำตามฟอร์มระบบเดิม (ประเภทบริการ → กลุ่ม → ผู้รับ) แต่ตามที่ตกลงกันในทีม **กลุ่มคืนทั้งหมดในครั้งเดียวแบบ
`GetOrganization`** ให้ frontend ทำ drop-down เดียวที่เลือกได้ทันที (ระบบเดิมเป็นหน้าต่างที่ต้องกดเข้าทีละชั้น)

ชื่อ API ใช้ `GetEmployeeGroup` (ไม่ใช่ `GetUserGroup` ตามชื่อตาราง) ให้คู่กับ `GetEmployeeByGroup`
ชื่อตาราง `TblUserGroup` คงเดิม เพราะ `TblEmployeeGroup` เป็นชื่อของตารางจับคู่อยู่แล้ว และชื่อตารางเป็นของ DB

ตารางระบบเดิม (MySQL `db_gcc_new`) → SQL Server: `user_group` → `TblUserGroup`, `users_user_group` → `TblEmployeeGroup`

- **`GET /ListOfValues/GetEmployeeGroup`:** `[{ id, refId, name }]` id เป็น string เรียงตามชื่อ
  - กลุ่มหลัก `refId == id` (12 กลุ่ม ตรงกับรายการในระบบเดิมทุกตัว) กลุ่มย่อย `refId` = กลุ่มหลัก (16 กลุ่ม) รวม 28
  - กรอง `Enable = 'T'` และกลุ่มหลักต้องเปิดอยู่ด้วย กลุ่มย่อยที่กลุ่มหลักถูกปิด (เช่น 1, 2, 63, 64) ไม่ถูกส่งมา
- **`GET /ListOfValues/GetEmployeeByGroup?groupId=`:** `[{ id, nameTh }]` รูปแบบเดียวกับ `GetEmployee`
  - พนักงาน `IsEnable = 'T'` ใน `TblEmployeeGroup` ของกลุ่มนั้นโดยตรง (ไม่รวมกลุ่มย่อย) เรียงชื่อ แล้วนามสกุล
  - ไม่ส่ง `groupId` → 400; กลุ่มปิด/ไม่มี → `[]`
  - แยกโค้ดต่อชื่อเป็น `FullNameTh` ใช้ร่วมกับ `GetEmployee`
- ผลทดสอบจริง: กลุ่ม 28 (หลัก 12), กลุ่ม 5 ได้ 34 คน (ตรงกับรูป drop-down ระบบเดิม), กลุ่ม 43 ได้ `[]`,
  ไม่ส่ง `groupId` ได้ 400, ไม่มี token ได้ 401

- [ ] **ข้อมูลนำเข้าจากระบบเดิมขาดเล็กน้อย** (เทียบ MySQL `db_gcc_new` กับ SQL Server เมื่อ 25 พ.ย.):

      | ตาราง | MySQL | SQL Server |
      |---|---|---|
      | `users_user_group` → `TblEmployeeGroup` | 2,054 | 2,052 (ขาด 2 แถว) |
      | `tbl_employee` เปิดใช้งาน (`is_enable` T) → `TblEmployee` `IsEnable = 'T'` | 420 | 419 (ขาด 1 คน) |
      | `tbl_employee` ทั้งหมด → `TblEmployee` | 2,019 | 562 |

      คนที่ขาด 1,457 คนเกือบทั้งหมดปิดใช้งานแล้ว (ลาออก) จึงถือว่าตั้งใจไม่นำเข้า แต่ `TblEmployeeGroup` ยังมี
      1,507 แถวที่ชี้ไปหาพนักงานพวกนี้ API ไม่ได้รับผล (join กับ `TblEmployee` และกรอง `IsEnable = 'T'`)
      ที่ต้องตามต่อ: ให้คนที่นำเข้าข้อมูลหาพนักงานที่เปิดใช้งาน 1 คน และ 2 แถวของกลุ่มที่ขาด แล้วเติมให้
