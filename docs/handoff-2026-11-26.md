ไฟล์: [Data/ApplicationDbContext.cs](../Data/ApplicationDbContext.cs), [Models/TblService.cs](../Models/TblService.cs)

  - `HasNoKey()` → `HasKey(e => e.Id).IsClustered(false)` และ `TblService.Id` เปลี่ยนจาก `string?` เป็น `string`

    (ตาราง backup ก็เป็นแบบนี้ แสดงว่าคอลัมน์ขยายไว้ก่อนวันนี้ แต่ยังไม่ได้ scaffold ใหม่)

- **ตาราง backup `TblService_bak_20261126`** ติดมากับการ scaffold ด้วย ลบ `Models/TblServiceBak20261126.cs`
  และ `DbSet`/mapping ของมันออกแล้ว ถ้ายังไม่ drop ตารางนี้ ต้องลบซ้ำทุกครั้งที่ scaffold
