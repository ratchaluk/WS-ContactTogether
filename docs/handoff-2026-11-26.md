### 6. เปิด CORS (ใหม่)
ไฟล์: [Program.cs](../Program.cs), `CLAUDE.md`

- default policy: **ทุก origin, ทุก header, ทุก method** ไม่เปิด credentials (token ส่งทาง header `Authorization` ไม่ได้ใช้ cookie
  ถ้าอนุญาตทุก origin แล้ว ASP.NET ก็ไม่ยอมให้เปิด credentials อยู่แล้ว) และ expose `Content-Disposition` ให้หน้าเว็บอ่านชื่อไฟล์ export ได้
- วาง `app.UseCors()` ไว้หลัง `UseHttpsRedirection()` และก่อน `UseAuthentication()` เพื่อให้ preflight (OPTIONS) ของ endpoint ที่ต้อง login ผ่านโดยไม่ต้องมี token
- frontend ยังเรียกผ่าน rewrite ของ Vercel (`/api/backend/*`) ซึ่งไม่ต้องใช้ CORS CORS มีผลกับการเรียกตรงจากเบราว์เซอร์ (เว็บอื่น / เครื่องมือทดสอบ)
