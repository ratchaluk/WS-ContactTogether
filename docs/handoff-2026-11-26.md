### 6. เปิด CORS (ใหม่)
ไฟล์: [Program.cs](../Program.cs), `CLAUDE.md`

- default policy: **ทุก origin, ทุก header, ทุก method** ไม่เปิด credentials (token ส่งทาง header `Authorization` ไม่ได้ใช้ cookie
  ถ้าอนุญาตทุก origin แล้ว ASP.NET ก็ไม่ยอมให้เปิด credentials อยู่แล้ว) และ expose `Content-Disposition` ให้หน้าเว็บอ่านชื่อไฟล์ export ได้
- วาง `app.UseCors()` ไว้หลัง `UseHttpsRedirection()` และก่อน `UseAuthentication()` เพื่อให้ preflight (OPTIONS) ของ endpoint ที่ต้อง login ผ่านโดยไม่ต้องมี token
- frontend ยังเรียกผ่าน rewrite ของ Vercel (`/api/backend/*`) ซึ่งไม่ต้องใช้ CORS CORS มีผลกับการเรียกตรงจากเบราว์เซอร์ (เว็บอื่น / เครื่องมือทดสอบ)

1. `dotnet run` แล้วรัน `login` ใน `.http` เก็บ `@token`
2. `POST /Report/GetReport01` ช่วง `2026-07-01T08:00:00`–`2026-07-31T17:00:00` → 200 `พบข้อมูล 174 รายการ`
3. `GET /Services/GetServiceById?id=BCE7C3A18761454F916187ED551C1084` → 200; `GET /Services/GetServiceOperations?serviceId=...` → 200
4. `GET /Home/GetInboxServices` / `GET /Home/GetProcessingServices` → 200 envelope (`man` ได้ `[]`)
5. `DELETE /Services/DeleteServiceOperations`: ไม่มี token → 401, `?id=abc` หรือไม่ส่ง id → 400,
   GUID ที่ไม่มี → 404; สร้างงานด้วย `AddNewServiceOperations` → ลบ → 200 `isEnable: "F"` → หายจาก
   `GetServiceOperations` → ลบซ้ำ / `UpdateServiceOperations` → 404
6. `GET /Home/InboxStream` (`curl -N -H "Authorization: Bearer <token>"`): ไม่มี token → 401; ได้ `retry`/`ready` ทันที และ `: ping`
   ทุก 25 วินาที; logout token นั้น → stream ปิดภายใน 25 วินาที และต่อใหม่ได้ 401
   เปิด stream ของ `man` ค้างไว้ แล้ว: เพิ่มงานให้คนอื่น → ไม่มีสัญญาณ; เปลี่ยนผู้รับเป็น `man` → `updated` (รายการรับมีเรื่องนั้น);
   `ReceiveService` → `received` (หายจากรายการรับ); เปลี่ยนผู้รับไปคนอื่นแล้วกลับ → `updated` 2 ครั้ง; ลบงาน → `removed`
   ทุกสัญญาณมาภายใน 1 วินาที และ log ของ notifier แสดง stream เปิด 3 / ปิด 3 (ไม่มีค้าง)

   `Access-Control-Allow-Origin: *`; `POST /Auth/login` และ `POST /Report/ExportReport01?format=xlsx` พร้อม `Origin` → 200 มี
   `Access-Control-Allow-Origin: *` และ `Access-Control-Expose-Headers: Content-Disposition`; ไม่ส่ง `Origin` → ไม่มี header CORS (เหมือนเดิม)
