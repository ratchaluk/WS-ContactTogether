ไฟล์: [Controllers/ListOfValuesController.cs](../Controllers/ListOfValuesController.cs),
[Dtos/AreaResponse.cs](../Dtos/AreaResponse.cs), [Helper/AreaQueries.cs](../Helper/AreaQueries.cs),

(commit `14987b1`, scaffold sync `4764b1b`)

- `GET /ListOfValues/GetArea?areaType=PROVINCE|DISTRICT|SUBDISTRICT&refId=` — lookup พื้นที่แบบ list แบน

## วิธีทดสอบด่วน
1. `dotnet run` (ต้องมี user-secrets: `ConnectionStrings:DefaultConnection`, `Jwt:Key` ≥ 32 ตัว)
2. รัน `login` ใน `.http` เก็บ `@token`
3. `GET /Services/GetServiceById?id=<id>` → response **ไม่มี** `areaPath` แต่ **ยังมี** `areaId`
4. `GET /Account/GetAccountById?id=<id>` → **ยังมี** `areaPath` (ไม่กระทบ)
5. `GET /ListOfValues/GetArea?areaType=PROVINCE` → ได้ list จังหวัด; ส่ง `refId` ต่อเพื่อได้อำเภอ/ตำบล
